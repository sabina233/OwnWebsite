# 前端项目文档

## 项目目标

为个人网站提供用户界面，包含公开页面、私密日记页面和管理后台。

## 技术栈

- Vue 3 + TypeScript
- Vite构建工具
- Pinia状态管理
- Vue Router路由
- Element Plus UI组件库
- md-editor-v3 Markdown编辑器
- Giscus评论系统
